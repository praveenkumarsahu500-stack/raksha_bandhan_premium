# Raksha Bandhan Premium 🎀

A beautiful, premium celebration website dedicated to the sacred festival of Raksha Bandhan - celebrating the bond of love and protection between siblings.

## Features ✨

### 🎨 Modern Design
- Premium gradient color scheme with traditional festival colors (Saffron, Red, Gold)
- Smooth animations and hover effects
- Fully responsive design that works on all devices
- Beautiful typography and visual hierarchy

### 🖼️ Photo Gallery
- Interactive image gallery with 3 memorable photos
- Hover effects with zoom and rotation
- Click to expand modal for full-size viewing
- Smooth transitions and animations

### 🎵 Music Player
- Integrated audio player for Raksha Bandhan devotional music

### 📱 Responsive
- Mobile-friendly design
- Tablet and desktop optimized
- Touch-friendly interactive elements

### ⚡ Interactive Features
- Smooth scroll navigation
- Modal image expansion

## How to Use 🚀

1. **Clone the Repository**
   ```bash
   git clone https://github.com/praveenkumarsahu500-stack/raksha_bandhan_premium.git
   cd raksha_bandhan_premium
   ```

2. **Add Your Photos**
   - Replace `photo1.jpg`, `photo2.jpg`, and `photo3.jpg` in the `photos/` folder with your own images
   - Images should ideally be in landscape orientation (3:2 or 16:9 aspect ratio)

3. **Add Your Music**
   - Replace `raksha-bandhan.mp3` in the `music/` folder with your own audio file
   - Supports MP3, WAV, and other common audio formats

4. **Open in Browser**
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     python -m http.server 8000
     # Then visit http://localhost:8000
     ```

## Customization 🎨

### Colors
Edit the CSS variables in the `<style>` section:
```css
:root {
    --primary-color: #d4af37;      /* Gold */
    --secondary-color: #c41e3a;    /* Red */
    --accent-color: #ffd700;       /* Bright Gold */
    --saffron: #ff9933;            /* Saffron */
}
```

### Text Content
- Edit any text directly in the HTML
- Change section titles, descriptions, and messages
- Add your own personal touches

### Images
- Replace photos with your own memories
